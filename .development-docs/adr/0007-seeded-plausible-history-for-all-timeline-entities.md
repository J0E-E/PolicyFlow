# 0007 — Seeded plausible event history for every timeline-bearing entity

Baseline (seeded) records of any entity type that gains a timeline or trace surface get
seeded plausible event history, so those surfaces are never empty. P1.9 set this for
leads; P2.5 extends it to opportunities and policies as a standing convention — the
alternative ("predates event capture" empty-state) was rejected because empty flagship
surfaces undercut the event-driven demo story. Source: brd-P2.5-timeline-correlation-trace.md §6, §8.
